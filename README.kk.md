# Webmarka Редколлегия

Joomla 6 үшін орыс және қазақ мәтінінің типографы мен алдын ала редакциясы. «Тырнақша», сызықша, минус, үзілмейтін бос орын, ондық үтір және «ё» әрпін қояды — редактордағы батырмамен және материал сақталғанда өзі.

[Русский](README.md) · [English](README.en.md)

## Нені түзетеді

Қазақ мәтіні — Алтынсарин қабаты (kk-redkollegiya ішіндегі kk_typo, Y01–Y14 ережелері): `Ол "Қазақ" - деді` → `Ол «Қазақ» — деді`, `т. б.` → `т.б.`, `Қ. К. Тоқаев` → `Қ.К. Тоқаев`, `2020-2025` → `2020–2025`, `5 млн. теңге` → `5 млн теңге`. Басылым ережелері: `-0.5%` → `−0,5%`, `₸ 8,5 млрд` → `₸8,5 млрд`.

Орыс мәтіні — «Мильчин» типографы мен «ё» әрпінің сенімді сөздігі (eyo).

Мағынаны, грамматиканы, кодты, сілтемелерді, поштаны, `{loadmoduleid 5}` сияқты плагин шақыруларын, тегтер мен атрибуттарды өзгертпейді.

## Қай жерде жұмыс істейді

- Редактордағы **«Типограф» батырмасы**: TinyMCE-дегі «Мазмұн» мәзірі мен панелі. TinyMCE-де бір Ctrl+Z бүкіл өткізуді болдырмайды.
- **Материалды сақтағанда**: мәтін, тақырып, метасипаттама, суреттің жазуы мен балама мәтіні. Мәтін тазартылғаннан кейін, ең соңынан жүреді.
- **«Компоненттер → Webmarka Редколлегия»**: мәтінді тексеру, соңғы өткізулер журналы.

## Орнату

Пакетті [шығарылымдардан](https://github.com/bsakhanov/wmarka_redkollegiya/releases) «Жүйе → Орнату → Кеңейтімдер» арқылы орнатыңыз. Талаптар: Joomla 6.0 және одан жоғары, PHP 8.3 және одан жоғары.
