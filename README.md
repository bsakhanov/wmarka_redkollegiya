# Webmarka Редколлегия

Типограф и пред-редактура русского и казахского текста для Joomla 6. Расставляет «ёлочки», тире, минус, неразрывные пробелы, десятичную запятую и букву «ё» — кнопкой в редакторе и сам при сохранении материала.

[English](README.en.md) · [Қазақша](README.kk.md)

## Что правит

| было | стало | правило |
| --- | --- | --- |
| `"Самрук-Казына" еще не ответил...` | `«Самрук-Казына» ещё не ответил…` | кавычки, ё, многоточие |
| `Нацбанк - регулятор` | `Нацбанк — регулятор` (перед тире неразрывный пробел) | тире |
| `Нацбанк – регулятор` | `Нацбанк — регулятор` | короткое тире между словами |
| `- Привет, - сказал он.` | `— Привет, — сказал он.` | тире реплики в начале абзаца |
| `в 2020-2025 гг.` | `в 2020–2025 гг.` | диапазон |
| `инфляция -0.5%` | `инфляция −0,5%` | минус, десятичная запятая |
| `на 0.25 п.п.` | `на 0,25 п. п.` | процентные пункты |
| `5 млн. тенге` | `5 млн тенге` | «млн» без точки внутри предложения |
| `₸ 8,5 млрд` | `₸8,5 млрд` | знак валюты перед числом — слитно |
| `в Астане`, `5 кг`, `т.е.` | с неразрывными пробелами | предлоги, единицы, сокращения |
| `cлово` (латинская c) | `слово` | двойники букв, невидимые знаки |

Казахский текст правит слой Алтынсарина: `Ол "Қазақ" - деді` → `Ол «Қазақ» — деді`, `т. б.` → `т.б.`, `Қ. К. Тоқаев` → `Қ.К. Тоқаев`; правила издания добавляют тире после знака препинания (`Сәлем, - деді ол` → `Сәлем, — деді ол`) и в начале абзаца.

Чего типограф не делает: не правит смысл, грамматику и пунктуацию по смыслу, не трогает код, ссылки, почту, вызовы плагинов вида `{loadmoduleid 5}`, теги и атрибуты разметки. Вставки остаются как есть: фреймы, `<video>` и `<audio>`, сценарии, цитаты-заглушки соцсетей (X/Twitter, Instagram, TikTok, Facebook, Threads, Bluesky, Reddit), метки встраивания Webmarka Clean. У видео [Wmarka Media](https://github.com/bsakhanov/com_wmarkamedia) поправляются только подпись и текст ссылки-заглушки; адрес ролика, картинка и атрибуты не трогаются. Непарные прямые кавычки (цитата на несколько абзацев) остаются как есть: угадывать, где она открывается и где закрывается, типограф не берётся.

## Вычитка

Кнопка «Вычитка» рядом с «Типографом» ничего не меняет сама: она показывает находки, а вносит только принятые — по месту и дословной цитате, одним шагом. Это механическая часть слоёв [русской Редколлегии](https://github.com/beaverbeard/redkollegiya) — то, что проверяется поиском и счётом, без языковой модели и без токенов:

| слой | что находит | правка |
| --- | --- | --- |
| Слопотрон | следы чат-ботов (`oaicite`, `contentReference`, 【】, `<\|im_end\|>`, `&mdash;` буквами), рамки ответа («Конечно, вот черновик…», «Надеюсь, было полезно»), призывы из соцсетей | убрать — можно принять скопом |
| Слопотрон | клише («важно отметить, что», «играет ключевую роль»), слова-маркеры («ключевой», «инновационный» — кроме рубрик новостей), стая: три маркера в абзаце | вводная — убрать; остальное к сведению |
| Чуковский, методология | канцелярит: «является», «данный», «позволяет», «осуществлять», «в рамках», «представляет собой»; однообразный ритм | «данный» → «этот», «позволяет снизить» → «даёт снизить», «на данный момент» → «сейчас» |
| Розенталь | «согласно приказа», «в течении года», «по окончанию работ», «не смотря на», «вследствии», «оплатить за», удвоенные слова | исправление |
| ё | «все равно», «о нем», «объем», «за счет» | «всё равно», «о нём», «объём», «за счёт» |

Для казахского текста вычитка берёт слои [казахской Редколлегии](https://github.com/bsakhanov/kk-redkollegiya):

| слой | что находит | правка |
| --- | --- | --- |
| Алтынсарин | двойники латиницы в словах («Iшкі»), латинская «ə» и чужие буквы, невидимые знаки — правит сам типограф; в вычитке — лишние знаки, стыки знаков, несбалансированные «ёлочки», пустые скобки | исправление |
| Шакарим | «РК», «ТОО», «АО», «ИП» вместо «ҚР», «ЖШС», «АҚ», «ЖК»; формы под запретом и по узусу корпуса («проект» → «жоба», но не «проектор») | замена |
| Байтурсынов | слово, набранное без казахских букв («Казакстан», «укиметі»); строчная после точки, число с аффиксом без дефиса («5ке»), валюта двумя видами | «Қазақстан», «үкіметі», «5-ке» — на решение; остальное к сведению |
| Валиханов | сверка с русским оригиналом по связи языков: изменённые и потерянные числа, даты, «мың / млн / млрд», латинские имена, термины | к сведению; изменённое число — ошибка |

Перенос kk_lint, kk_stem, kk_parity и kk_restore сверяется с оригиналом побуквенно: `KK_REDKOLLEGIYA=… python3 tests/parity/kk_compare.py`. Модель восстановления букв и список форм — открытые файлы kk-redkollegiya 0.14.0, обученные на корпусе [KazNERD](https://github.com/IS2AI/KazNERD) (ISSAI, CC BY 4.0): на его проверочных частях верны 99,5% подсказок при полноте 83,0% (`kaznerd_bench.py --forms … --strip 2500`); обновить — `tools/kk_open_model.py`. Словарь — как `kk_lint --forms`, без Hunspell.

Внутри цитат «…» канцелярит, клише и управление не проверяются: слова говорящего правят только при явной опечатке. Смысловую правку, запятые в обособлениях и фактчек механика не делает — это дело модели (ИИ-помощника сайта) и редактора.

## Правила издания и правила редакции

Кроме норм языка, у новостного сайта есть свой почерк. Типограф правит бесспорное сам: H1 в тексте становится H2, знаки и пробелы выходят за пределы гиперссылки, разряды разделяются пробелом, в прямой речи нет лишней запятой после «?» и «!». По выбору — время через двоеточие, «и так далее» полными словами, только «ёлочки».

Правила редакции «Вычитка» показывает находками; каждая группа включается в настройках: относительное время («сегодня», «вчера»), канцелярит редакции («в ходе», «озвучил», страдательный залог), названия (соцсети латиницей, «Интернет», должности и акиматы со строчной, без слова «город»), полные слова вместо «млн», «тыс.», «км» и адресных сокращений — с формой по числу и предлогу, строение текста (лид жирным, сайт ссылкой, подпись у снимка, уровни заголовков, цитаты) и заголовок (длина, кавычки, «сегодня»).

## Где работает

- **Кнопка «Типограф» в редакторе** — в меню «Контент» TinyMCE, на панели TinyMCE (по настройке плагина) и под CodeMirror или простым полем. Исправленный текст встаёт на место одним шагом: в TinyMCE одно Ctrl+Z возвращает текст до прогона. Язык — из поля «Язык» материала, «Все» — по буквам текста.
- **При сохранении материала** — текст, заголовок, метаописание, подписи и альтернативный текст снимков (что именно — в настройках). Обработчик идёт последним, после очистки текста ([Webmarka Clean](https://github.com/bsakhanov/plg_system_wmarka_clean)); адрес материала Joomla строит из заголовка раньше, «ёлочки» и тире в него не попадают.
- **«Компоненты → Webmarka Редколлегия»** — проверка текста с отметками правок (ничего не сохраняется), последние прогоны и итоги за 30 дней.
- **Из других расширений** — одна служба с настройками сайта:

```php
use Webmarka\Component\Redkollegiya\Administrator\Service\Typographer;

$result = Typographer::run($html, 'ru-RU', true, 'mcp', $articleId); // источник и номер — для журнала
$result->text;     // исправленный текст
$result->groups(); // ['quotes' => 4, 'nbsp' => 12, …]
```

Без Joomla ядро — обычные классы PHP: `(new Engine($options))->process($text, 'kk-KZ', false)`.

## Откуда правила

- **Русский текст** — перенос на PHP типографа [Мильчин](https://github.com/beaverbeard/milchin) (MIT): только правила, где верный ответ не зависит от смысла фразы. Правила, их коды и порядок те же.
- **Казахский текст** — перенос kk_typo из [казахской Редколлегии](https://github.com/bsakhanov/kk-redkollegiya), правила Y01–Y14, решённые по обычаю корпуса.
- **Буква «ё»** — безопасный словарь [eyo](https://github.com/e2yo/eyo-kernel) Дениса Селезнёва (MIT): только слова, где «е» вместо «ё» не бывает («ещё», «её», «счёт»). «Все — всё», «небо — нёбо» не трогаются; «объем» тоже — это ещё и форма глагола «объесть». Имена собственные из словаря («Артём», «Семёнов») по умолчанию не трогаются: имя пишут так, как в документах человека.
- **Правила издания** — то, чего Мильчин сознательно не делает: минус, десятичная запятая, «млн» без точки, длинное тире вместо короткого между словами, знак валюты. Ставятся только там, где ошибки быть не может: минус — перед числом после пробела, скобки или кавычки, когда слева не число («5 -3» и телефоны не трогаются); запятая — в числе перед единицей, процентом, валютой или словом «раз» («Joomla 6.2», «п. 3.2», «06.11.2026» не трогаются).

Совпадение переноса с оригиналами проверяется побуквенно: `tests/parity/compare.py` прогоняет одни и те же тексты через milchin.py и kk_typo.py и через PHP. При выпуске 0.1.0 совпали все 26 139 текстов при трёх наборах настроек: 2 523 из публичных документов обеих Редколлегий и 23 616 из закрытых корпусов — новостных статей и рабочих документов, целиком и по абзацам (в репозиторий они не входят).

## Настройки

«Компоненты → Webmarka Редколлегия → Настройки»:

- **Русский текст** — знак процента (`10%` или `10 %`), предлоги (однобуквенные или и двух-, трёхбуквенные), инициалы, короткое тире между словами, рубль знаком, даты ISO.
- **Казахский текст** — процент, знак номера, градусы, тире между словами.
- **Правила издания** — минус, десятичная запятая, «млн» без точки, тире в диапазоне (`2020–2025` или `2020—2025`), знак ₸ и $ перед числом (новостной стиль: `500 ₸` → `₸500`), единицы после числа.
- **Буква ё** — восстанавливать, снимать или не трогать; в именах собственных — отдельно.
- **Не трогать** — слова, которые не правит ни одно правило.
- **При сохранении** — текст, заголовок, метаописание, подписи снимков.
- **Журнал** — вести ли и сколько дней хранить.

Кнопку на панели TinyMCE и её место задают настройки плагина «Кнопка - Webmarka Редколлегия»; правка при сохранении работает, пока включён плагин «Содержимое - Webmarka Редколлегия».

## Слова от других расширений

Список «Не трогать» могут дополнять расширения сайта — например, словарь терминов издания. Плагин группы `redkollegiya` получает событие `onWmarkaRedkollegiyaWords` и дописывает свои слова:

```php
public static function getSubscribedEvents(): array
{
    return ['onWmarkaRedkollegiyaWords' => 'words'];
}

public function words(\Joomla\Event\Event $event): void
{
    $event->setArgument('words', array_merge($event->getArgument('words', []), ['Kaspi.kz', 'Ежов-банк']));
}
```

## Журнал

Кто, когда и в каком материале прогнал типограф, откуда (кнопка, сохранение, ассистент), на каком языке и сколько правок вышло по каким правилам. Сами тексты не пишутся. Правило, которое раз за разом правит одно и то же у одного автора, — повод для памятки; правило, которое правит «не то», видно по выросшему счёту.

## Установка

Пакет `pkg_wmarka_redkollegiya_v<версия>.zip` из [выпусков](https://github.com/bsakhanov/wmarka_redkollegiya/releases) — через «Система → Установка → Расширения». Плагины включаются сами при первой установке. Дальнейшие выпуски приходят в «Система → Обновление».

Требования: Joomla 6.0 и выше, PHP 8.3 и выше, расширения PHP `mbstring` и (желательно) `intl`. Проверено на Joomla 6.2.0 с PHP 8.3 и 8.4, вместе с Webmarka Clean 1.1.0.

Удаление пакета снимает компонент, оба плагина и таблицу журнала.

## Проверки

```bash
php tests/run.php                       # ядро: правила издания, ё, разметка, язык, защита, повторный прогон
MILCHIN=…/milchin.py KK_REDKOLLEGIYA=…/kk-redkollegiya python3 tests/parity/compare.py [файлы и папки]
REDKOLLEGIYA_CORPUS=папка_с_txt php tests/run.php   # плюс свой корпус: повторный прогон ничего не меняет
./build.sh                              # сборка в dist/: архив, SHA256SUMS.txt, updates.xml
tools/release.sh --dry-run              # выпуск: тег, архив на GitHub, updates.xml
```
